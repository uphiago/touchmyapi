# Historical design records

Files under `docs/superpowers/plans/` and `docs/superpowers/specs/` are immutable
planning snapshots. Some intentionally describe earlier Google-only authentication,
pre-GitHub workspace composition, or pre-delivery assumptions. They are not the
current runtime contract.

For the current state, use this order:

1. `specs/001-touchmyapi-platform/tasks.md` for accepted/open status;
2. `README.md` and `docs/product/user-journeys.md` for user-facing behavior;
3. `docs/operations/ovh-deployment.md` for production operations;
4. the dated `docs/reviews/` handoff for the latest evidence.
